# Week 3 Demo Canvas — CommonGrounds.Web ☕→☁️

Week 3's demo is terminal-and-editor theater: you create **CommonGrounds.Web** live (`dotnet new mvc` in `~/Repos/dotnet-web-dev-course/instructor/week-03/`), tour it, extend it, and deploy it — the coffee shop goes dynamic. **Deliberately different content from the lab:** you build Menu/Special; students build About/Hello in *First Flight*.

- `demo-script.md` — the edit-by-edit cue sheet, keyed to slide numbers, with a [clickable hosted version](https://jgrissom.github.io/dotnet-web-dev/week-03/demo/script.html). It's fully self-contained — every command and code block you type or paste is in it.
- No committed app here: the whole demo app is ~30 lines of changes to a fresh template, and the script *is* the finished reference. Rehearse by running the script once (≈15 min).

> [!IMPORTANT]
> Before class: make sure `~/Repos/dotnet-web-dev-course/instructor/week-03/` exists and holds no `CommonGrounds.Web` from a rehearsal, and decide your Azure app name (`cg-web-` + digits). If you rehearsed the deploy, either reuse the same name (it just redeploys) or delete the rehearsal app so class sees the real first-run experience.
