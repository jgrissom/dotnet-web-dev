# Week 1 — Course Intro, Setup & JavaScript Refresher

Setup night plus a rapid JS recalibration: modern idioms, arrays/objects the LINQ way, and a DOM/`fetch` tour. Students leave with a verified toolchain and their first code deployed to GitHub Pages.
